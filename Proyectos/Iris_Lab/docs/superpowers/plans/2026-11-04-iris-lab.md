# Iris Lab Implementation Plan

**Goal:** Aplicación PyQt6 de análisis, exploración, entrenamiento y predicción de Iris.
**Architecture:** core.py independiente de Qt; widgets.py para componentes; window.py
para las cinco vistas, señales y trabajo asíncrono; app_iris.py como entrada.
**Tech Stack:** PyQt6, pandas, NumPy, scikit-learn, Matplotlib, unittest/QtTest.
**Spec:** docs/superpowers/specs/2026-11-04-iris-lab.md

## Restricciones
Usar archive/Iris.csv; no modificar los originales. Excluir Id de X. Estratificación,
semilla fija por defecto, prueba 30 %, entropía, profundidad 3. CV solo entrenamiento.
Sin métricas inventadas, pausas artificiales o bloqueos del hilo gráfico durante entrenamiento.

## Riesgos a comprobar
CSV sin columnas / NaN / infinito / etiqueta desconocida: error explicativo sin perder estado.
Cambio de dataset: invalidar modelo y predicción anteriores.
Cambio de parámetros: marcar resultados anteriores y exigir volver a entrenar para actualizar.
Cerrar durante worker: esperar fin sin destruir hilo activo.
Duplicados: contar coincidencias entre particiones y explicarlo en evaluación.
